# workspace

[![Лицензия](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Зонтичный инструмент систематизации рабочего пространства: единый стандарт окружения — mise
для инструментов и демонов сервисов — и гибкая поставка инфраструктуры дочерним проектам.
Задачи за пределами пути — [кейсы](./docs/use-cases.md); правка — [CONTRIBUTING.md](./CONTRIBUTING.md); понятия — [глоссарий](./GLOSSARY.md).

## Что нужно

- [mise](https://mise.jdx.dev/) — единственный менеджер окружения;
- docker или podman — сервисы общего набора (OpenSearch, MinIO) и одноразовые прогоны;
- `vm.max_map_count=262144` на хосте — требует OpenSearch (`sysctl -w vm.max_map_count=262144`);
- git;
- `bash` и `curl` — установка поставки tessera в шаге 2 скачивает источники с GitHub;
- `python3` — команда `backlog`, которую ставит поставка tessera.

## Шаг 1. Установить инструментарий

Выполните `mise install` — установится всё закреплённое в `mise.toml`: node, python, openspec
и pitchfork (supervisor демонов).

## Шаг 2. Инициализировать локальное окружение

Выполните `mise run init` — задача создаст `.env` из шаблона `.env.example`, каталог
`.claude-accounts`, записи `.gitignore` и поставку tessera: навыки — ссылками в каталоги
навыков проекта, правила — копиями в `.tessera/rules/`, точку входа агентов `AGENTS.md`.
Повторный запуск ничего не перезаписывает. Чтобы харнес увидел навыки, перезапустите
его сессию.

## Шаг 3. Заполнить .env

Откройте `.env` и заполните значения, перечисленные в `.env.example`: эндпоинт embeddings
классификатора и креды сервисов общего набора (postgres, opensearch, minio). Секреты
хранятся только здесь — файл скрыт от git.

## Шаг 4. Поднять сервисы общего набора

Выполните `mise run env-up` — демоны mise поднимут PostgreSQL (нативный процесс), OpenSearch
с OpenSearch Dashboards и MinIO (контейнеры) и дождутся готовности. Сервисы слушают
фиксированные localhost-порты: `5432`, `9200`, `5601` (UI Dashboards), `9000`; координаты
подключения раздаёт секция `[env]` через каскад mise. Остановка — `mise run env-down`,
состояние — `mise run env-status`.

## Куда дальше

- Классификация, раскладка проектов, требования, рабочие процессы — в [документе кейсов](./docs/use-cases.md).
- Перечень задач окружения печатает `mise tasks`.
- Изменения репозитория идут через OpenSpec: перечень лежащих изменений печатает `openspec list`.
- Если вы хотите править репозиторий — в [CONTRIBUTING.md](./CONTRIBUTING.md).

## Ограничения

- Бейдж версии отсутствует: носителя версии в репозитории нет, история остаётся в git.
- Docker или podman — предусловие: без них не поднимутся OpenSearch и MinIO.
- mise daemons — экспериментальная фича mise: версии mise и pitchfork закреплены, смена
  формата деклараций оформляется отдельным изменением.
- Харнессы разработки (claude, codex, dsh) не поставляются: выбирайте свой инструмент —
  окружение его не навязывает.
- Версии источников поставки tessera не закреплены: установщик ставит ветку `main`
  репозиториев tessera, formular и mattpocock/skills; повторный запуск задачи обновляет её.
- Точка входа агентов — `AGENTS.md`, файл создаёт установщик tessera. Claude Code читает его
  сам с версии 2.1.277 и только пока в проекте и каталогах выше нет `CLAUDE.md`.
- Forge (миграции схемы данных) отключён; возвращение — отдельным изменением.
