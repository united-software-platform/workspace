# workspace

[![Лицензия](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Зонтичный инструмент систематизации рабочего пространства: единый стандарт окружения — mise
для инструментов, k3s для сервисов — и гибкая поставка инфраструктуры дочерним проектам.

## Что нужно

- [mise](https://mise.jdx.dev/) — менеджер инструментария;
- локальный кластер k3s с `kubectl` и `helm` — сервисы и одноразовые прогоны;
- `vm.max_map_count=262144` на хосте — требует OpenSearch (`sysctl -w vm.max_map_count=262144`);
- git.

## Шаг 1. Установить инструментарий

Выполните `mise install` — установится всё закреплённое в `mise.toml`: node, python и openspec.

## Шаг 2. Инициализировать локальное окружение

Выполните `mise run init` — задача создаст `.env` из шаблона `.env.example`, каталоги `.ssh`
и `.claude-accounts`, записи `.gitignore` и SSH-ключ проекта. Повторный запуск ничего
не перезаписывает.

## Шаг 3. Заполнить .env

Откройте `.env` и заполните значения, перечисленные в `.env.example`: git-хост для SSH
и эндпоинт embeddings классификатора. Секреты хранятся только здесь — файл скрыт от git.

## Шаг 4. Просканировать проект

Выполните `mise run tldr-scan` — код проекта просканируется образом tldr (Job в кластере),
отчёты об устройстве, безопасности, качестве и архитектуре лягут в `reports/tldr`.

## Куда дальше

- Перечень задач окружения печатает `mise tasks`.
- Применить зонтичный чарт сервисов общего набора — `mise run k3s-apply` (чарт `deploy/workspace`).
- Изменения репозитория идут через OpenSpec: перечень лежащих изменений печатает `openspec list`.
- Правила репозитория подключены в [CLAUDE.md](./CLAUDE.md) и [AGENTS.md](./AGENTS.md).

## Ограничения

- Бейдж версии отсутствует: носителя версии в репозитории нет, история остаётся в git.
- Кластер k3s рассчитан на Linux-хост; на macOS и Windows нужен раннер-VM — этот случай
  стандарт не покрывает.
- Харнессы разработки (claude, codex, dsh) не поставляются: выбирайте свой инструмент —
  окружение его не навязывает.
- Forge (миграции схемы данных) отключён; возвращение — отдельным изменением.
