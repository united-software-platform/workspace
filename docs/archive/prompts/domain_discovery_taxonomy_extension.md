# Domain Discovery & Taxonomy Extension

## Цель

Выявление отсутствующих предметных доменов и расширение таксономии SPCF с сохранением согласованности иерархии L1–L4.

## Контекст

Тестовый прогон:
`projects/20261116214536.json`

Обнаруженная проблема:

При классификации досок и систем управления недвижимостью предметная область определена некорректно.

Текущая классификация:
- L1: DOM-003 — Торговля и коммерция (не соответствует предметной области).
- L2–L3: отсутствуют подходящие категории.
- L4:
  - Агентов.NET — SOL-034 (близкое решение).
  - БЦИнформ — SOL-034 (близкое решение).

## Задачи

### 1. Исследование предметной области

- Проанализировать объекты классификации из тестового прогона.
- Исследовать в интернете соответствующие отраслевые классификации и устоявшуюся терминологию.
- Определить наиболее подходящий домен L1 для систем управления недвижимостью.
- Обосновать выбор домена.

### 2. Проработка иерархии

Для выявленного домена проработать всю иерархию:

- L1 — Domain.
- L2 — Subdomain.
- L3 — Problem Domain.
- L4 — Solution / Solution Type.

Использовать актуальные отраслевые источники и реальные примеры существующих систем.

### 3. Расширение справочников

- Проверить существующие категории на предмет повторного использования.
- Определить недостающие категории.
- Добавить необходимые элементы в соответствующие справочники.
- Сохранить существующие идентификаторы и связи.
- Не создавать дублирующие категории.

### 4. Валидация

Повторно классифицировать исходные объекты из тестового прогона.

Проверить:
- Корректность определения L1.
- Соответствие L2–L3 предметной области.
- Адекватность L4.
- Отсутствие конфликтов с существующей таксономией.

## Результат

1. Обновлённые справочники SPCF.
2. Обоснование нового домена и его иерархии.
3. Результаты повторной классификации.
4. Краткий отчёт об изменениях и выявленных ограничениях.
