# Problem Domain Enrichment

## Цель

Расширение справочника L3 Problem Domains на основе реальных отраслевых проблем, бизнес-кейсов и практики применения программных систем.

## Контекст

Тестовый прогон:
`projects/20261116211243.json`

Обнаруженная проблема:

При ручной проверке справочников выявлены значительные пробелы и недостаточная детализация предметных проблем в отдельных доменах.

Справочник:
`tools/classifier/taxonomy/l3_problem_domains.json`

## Область расширения

Обязательно проработать следующие домены:

| ID | Домен |
|---|---|
| DOM-002 | Государственный сектор |
| DOM-003 | Торговля и коммерция |
| DOM-008 | Разработка программного обеспечения |
| DOM-017 | Аналитика и отчётность |
| Новый домен | Недвижимость |

Для недвижимости использовать результат исследования предметной области и согласованный домен из workflow Domain Discovery & Taxonomy Extension.

## Задачи

### 1. Исследование

Для каждого домена:
- Исследовать актуальные отраслевые проблемы.
- Найти реальные бизнес-кейсы и сценарии применения программных систем.
- Изучить отраслевую терминологию.
- Определить проблемы, которые отсутствуют в текущем справочнике.

Использовать авторитетные отраслевые источники, документацию продуктов, исследования и практические кейсы.

### 2. Расширение L3

Для каждого домена:
- Проанализировать существующие Problem Domains.
- Выявить пробелы в покрытии.
- Сформировать недостающие категории.
- Добавить новые категории в `l3_problem_domains.json`.

Каждая категория должна:
- Описывать конкретную предметную проблему.
- Быть независимой от конкретного программного продукта.
- Иметь понятное название и описание.
- Отражать реальную отраслевую практику.
- Не дублировать существующие категории.

### 3. Проверка качества

Проверить:
- Полноту покрытия предметных проблем.
- Отсутствие семантических дублей.
- Корректность принадлежности домену L1.
- Согласованность терминологии.
- Возможность применения категорий для классификации реальных проектов.

## Результат

1. Расширенный `l3_problem_domains.json`.
2. Новые категории с описаниями и обоснованием.
3. Ссылки на источники исследования.
4. Краткий отчёт по каждому домену:
   - Что было обнаружено.
   - Какие пробелы выявлены.
   - Что добавлено.
   - Как изменилось покрытие.
