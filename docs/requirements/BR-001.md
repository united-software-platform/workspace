# BR-001: Собранный контекст проделанной работы

Бизнес-требование: находить проделанную работу во всех своих проектах за любой период
и получать собранный контекст — что было сделано, в каком проекте и как. Карточка сформирована
операцией `formular`, принята владельцем на стоп-знаке.

## Карточка требования

| Поле | Значение |
|---|---|
| ID | BR-001 |
| Name | Собранный контекст проделанной работы |
| Description | Бизнес должен уметь находить проделанную работу во всех своих проектах за любой период и получать собранный контекст: что было сделано, в каком проекте и как |
| Rationale | Работа размазана по многим проектам и большим периодам; ручной поиск — найти проект, перебрать файлы/классы/методы, искать в git-истории — не собирает полный контекст «как это было сделано», найденное оказывается разрозненными обрывками |
| Business Outcome | Ответ на вопрос «как это делали» собирается из истории проектов целиком за минуты вместо часов перебора; знание о проделанной работе перестаёт теряться со временем и уходить вместе с памятью |
| Success Criteria | Запрос по названию или смыслу работы возвращает собранный контекст — проект, суть изменения, файлы, коммиты, способ реализации — без ручного перебора; проверка: на трёх известных прошлых работах собранный контекст полон и совпадает с фактической историей |
| Priority | `Must` |
| Status | `Proposed` |
| Source | Владелец (Alexey Gaybovich), диалог 2026-11-21, прогон formular `20261121234009-past-work-search` |

> **Внимание:** дальнейшая жизнь требования (смена статуса, правки полей) идёт в этом файле;
> беклог прогона `backlog/formular/20261121234009-past-work-search/` — неизменное свидетельство
> формирования.
