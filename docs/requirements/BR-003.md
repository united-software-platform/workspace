# BR-003: Сборка нового проекта из существующих технических решений

Бизнес-требование: извлекать выбранные технические решения из проектов рабочего пространства
и собирать из них другой проект копией всех артефактов каждого решения. Карточка сформирована
операцией `requirement-add`, принята владельцем на стоп-знаке. Понятие «Техническое решение
(Technical Solution)» вводит [BR-002](./BR-002.md).

## Карточка требования

| Поле | Значение |
|---|---|
| ID | BR-003 |
| Name | Сборка нового проекта из существующих технических решений |
| Description | Бизнес должен уметь извлекать выбранные технические решения из проектов рабочего пространства и собирать из них другой проект — новый git-репозиторий пространства по раскладке — копией всех артефактов каждого решения |
| Rationale | Готовые технические решения заперты внутри своих проектов: извлечь решения одного проекта, чтобы собрать из них другой проект, нельзя; новый проект собирается с нуля, готовая работа не переиспользуется |
| Business Outcome | Новый проект пространства собирается из существующих технических решений за часы вместо сборки с нуля; переиспользование решений становится штатным путём сборки нового проекта |
| Success Criteria | выбранные решения копируются в новый проект целиком — все артефакты каждого; зависимости каждого решения показываются до копирования, перенос зависимостей решает владелец; копия одноразовая, без синхронизации с проектом-источником; новый проект — git-репозиторий по раскладке пространства; сборка <= 2 ч из 5 решений; проверка: сборка из 5 выбранных решений известного проекта; пропущенные артефакты <= 0 шт |
| Priority | `Should` |
| Status | `Proposed` |
| Source | Владелец (Alexey Gaybovich), диалог 2026-11-22, прогон requirement-add `20261122030257-assemble-project-from-solutions` |
