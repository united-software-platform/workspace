# BR-002: Поиск технических решений по проектам пространства

Бизнес-требование: находить нужное техническое решение по проектам рабочего пространства
запросом по названию и по смыслу. Карточка сформирована операцией `requirement-add`, принята
владельцем на стоп-знаке. Вводит понятие «Техническое решение (Technical Solution)».

## Карточка требования

| Поле | Значение |
|---|---|
| ID | BR-002 |
| Name | Поиск технических решений по проектам пространства |
| Description | Бизнес должен уметь находить нужное техническое решение (Technical Solution) — законченную функциональность проекта целиком — по проектам рабочего пространства, внесённым в учёт, запросом по названию и по смыслу |
| Rationale | Технические решения разобщены по десяткам проектов пространства, количество решений в проектах различается; в репозиториях проектов маркера решения нет, решения находимы только по смыслу; нужное решение нельзя найти по проектам пространства, знание о готовых решениях теряется, работа повторяется заново |
| Business Outcome | Нужное техническое решение находится по всему пространству за минуты вместо перебора десятков проектов; готовые решения становятся видимыми и доступными для переиспользования |
| Success Criteria | когда запрос по названию, техническое решение с проектом и артефактами; когда запрос по смыслу, техническое решение с проектом и артефактами; никогда ручной перебор проектов; поиск <= 1 мин на десятках проектов; проверка: на 10 известных решениях поиск находит каждое; пропущенные решения <= 0 шт |
| Priority | `Must` |
| Status | `Proposed` |
| Source | Владелец (Alexey Gaybovich), диалог 2026-11-22, прогон requirement-add `20261122030251-solution-search` |

> **Внимание:** дальнейшая жизнь требования (смена статуса, правки полей) идёт в этом файле;
> беклог прогона `backlog/requirement-add/20261122030251-solution-search/` — неизменное
> свидетельство формирования. Требование отличается от [BR-001](./BR-001.md) объектом поиска:
> здесь — переиспользуемое техническое решение, там — собранный контекст проделанной работы.
> Найденные решения потребляет [BR-003](./BR-003.md) — сборка нового проекта из существующих
> решений.
