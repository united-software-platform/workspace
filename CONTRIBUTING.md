## Устройство репозитория

| Что | Где |
|-----|-----|
| Правила репозитория | `.tessera/rules/` — копии поставки tessera, ведёт установщик (`mise run init-tessera`) |
| Терминология домена | [`GLOSSARY.md`](./GLOSSARY.md) |
| Точка входа агентов | `AGENTS.md` — создаёт установщик tessera |
| Собственные навыки проекта | `.claude/skills/` |
| Навыки поставки tessera | ссылки установщика в `.agents/skills/` и `.claude/skills/`, вне git |
| Утилита классификации | `tools/classifier/` |
| Утилита раскладки проектов | `tools/layout/` |
| Спецификации и изменения | `openspec/` |
| Карточки требований | `docs/requirements/` |
| Документ кейсов | `docs/use-cases.md` |
| Свидетельства прогонов | `backlog/` |
| Шаблоны операций | `templates/` |
| Окружение: инструменты, задачи, демоны | `mise.toml` |

Каталог `.zcode/skills/` — жёсткие связи на `.claude/skills/`: правится один файл, второй
следует сам.

## Проверки

Проверки прогоняются до отправки изменений, каждая — своей командой:

```bash
openspec validate --all                      # согласованность изменений и спецификаций
cd tools/classifier && uv run pytest         # тесты классификатора, сеть не нужна
cd tools/classifier && uv run mypy src       # типы классификатора
cd tools/classifier && uv run ruff check .   # линтер классификатора
cd tools/layout && uv run pytest             # тесты раскладки, сеть не нужна
cd tools/layout && uv run mypy src           # типы раскладки
cd tools/layout && uv run ruff check .       # линтер раскладки
```

Полный перечень задач окружения печатает `mise tasks`.
