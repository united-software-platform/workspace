# Proposal

## Why

Классификатор карточек государственных автоматизированных информационных систем не находит
в таксономии подходящего архетипа L4 и относит их к ERP (SOL-001). Это систематически неверно:
ERP управляет внутренними ресурсами предприятия (производство, склад, закупки, финансы, кадры),
а государственная АИС — внешний контур взаимодействия ведомств и организаций с получателями
поддержки: приём регламентированной отчётности, ведение реестров, контроль использования мер.
Проблема подтверждена владельцем на реальном прогоне (карточка государственной АИС отчётности
и реестров; имя системы в артефакты не входит). Задача: WRSP-023,
https://github.com/united-software-platform/workspace/issues/12.

## What Changes

- В `tools/classifier/taxonomy/l4_solution_archetypes.json` добавляется запись `SOL-035`
  «Государственная автоматизированная информационная система» (code:
  `government-information-system`, name: `Government Information System`) во всех шести полях
  действующего формата.
- Счётчики приводятся к новому составу: `record_count` в `l4_solution_archetypes.json`
  34 → 35; `manifest.json` — L4 34 → 35 и `example_project.json` 3 → 4;
  `EXPECTED_COUNTS` в `tools/classifier/tests/test_taxonomy_loader.py` 34 → 35.
- В `tools/classifier/taxonomy/example_project.json` добавляется вымышленный пример
  «Region Support Registry — государственная АИС отчётности и реестров» (`fictional: true`)
  с ожидаемым назначением DOM-002 / SUB-005 / PRB-003 / SOL-035, все primary.
- Уровни L1–L3 не дополняются: DOM-002, SUB-005 и PRB-003 уже покрывают профиль
  государственной АИС. Правок кода классификатора нет — только данные таксономии и тест.

## Capabilities

### New Capabilities

- нет

### Modified Capabilities

- `classifier-taxonomy`: выгрузка таксономии получает архетип L4 для государственных АИС,
  вымышленный пример этого класса и согласованные счётчики состава.
