## Правки описаний по итогам валидации

При первой повторной классификации выявлены два отклонения, закрытые уточнением описаний
новых записей (в границах задач 2.3/2.4, терминология — по сводке исследования):

- SOL-036 дополнен явным охватом коммерческой недвижимости (офисы, бизнес-центры) — каталог
  бизнес-центров сначала уступал primary SOL-034 «Информационный веб-портал» (0.802 против 0.784);
  после правки SOL-036 primary с отрывом (0.826 против 0.802).
- PRB-027 сужен отраслевой привязкой (собственники, посредники, площади, коммерческие помещения) —
  генеричная формулировка «большие объёмы разрозненной информации» притягивала карточку
  интернет-магазина (регрессия L3 primary PRB-009 → PRB-027); после правки первичный PRB-009
  восстановлен, регрессий на контрольных карточках нет.

## Ограничения

- Выборка домена — две карточки прогона; деление домена (жилая/коммерческая, девелопмент, REIT)
  преждевременно — расширение отдельным изменением по новым прогонам.
- SUB-039 и SOL-037 валидированы только логикой состава и источников: карточек систем управления
  недвижимостью в прогоне нет — записи закрывают пробел превентивно; их уместность видна по
  соседним кандидатам: SUB-039 стабильно второй у обеих карточек прогона.
- Правило DOM-003 ↔ DOM-018 текстовое: ранжирование эмбеддингов уже отдаёт DOM-018 primary
  у обеих карточек, правило фиксирует норму на случай близких confidence.
