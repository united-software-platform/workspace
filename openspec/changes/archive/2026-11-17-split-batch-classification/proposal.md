# Proposal

## Why

Пакетный прогон сегодня один: `classify-batch` добывает данные каждого проекта веб-поиском,
выбирает источник и обогащает карточку фактами из него. Когда карточки уже составлены —
массивом JSON по входному контракту классификатора, — поиск и обогащение становятся лишней
работой: прогон требует переменных `WEBSEARCH_*`, тратит попытки на дополнение карточек
и привносит выбор источника, который для готовых карточек не нужен.

## What Changes

- **BREAKING**: навык `classify-batch` переименован в `classify-batch-enrich` — каталог
  `.claude/skills/classify-batch` переименовывается; вызов по старому имени перестаёт
  действовать, семантика прогона с поиском и обогащением не меняется.
- Новый навык `classify-batch` занимает освободившееся имя: пакетный прогон по готовым
  карточкам без веб-поиска и обогащения. Вход — JSON-массив карточек по входному контракту
  `tools/classifier/docs/contracts.md`: путь к файлу вне репозитория либо массив текстом
  вызова. Прогон идёт тем же мультиагентным порядком — фоновые агенты по одному на карточку —
  и завершается тем же итоговым файлом `projects/{штамп}.json` и сводным отчётом.
- Новый шаблон операции `classify-card-auto`: беклог элемента без стоп-знаков — карточка
  берётся готовой, утилита классификации вызывается напрямую один раз, без цикла дополнения;
  код `1` (`needs_confirmation`) даёт элементу статус `failed` с сохранением данных
  классификации.
- Окружение карточного прогона сужено: требуются только `EMBEDDINGS_*` и закоммиченная
  таксономия; переменные `WEBSEARCH_*` не проверяются и не нужны.

### Modified Capabilities

- `batch-project-classification`: навык enrich-прогона переименован в `classify-batch-enrich`
  (переформулировано требование «Навык пакетной классификации»); добавлены требования
  карточного прогона без обогащения — вход массивом карточек, шаблон операции
  `classify-card-auto` с одним вызовом утилиты, запись итогового файла без поля источника,
  окружение без `WEBSEARCH_*`. Существующие требования к выбору модели, порогу, устойчивости,
  приватности и сводному отчёту распространяются на оба навыка способности.

## Impact

- `.claude/skills/classify-batch/` — каталог переименован в `.claude/skills/classify-batch-enrich/`
  (`git mv`), `SKILL.md` дозаписан строкой версий.
- `.claude/skills/classify-batch/SKILL.md` — новый навык карточного прогона.
- `templates/classify-card-auto.md` — новый шаблон операции; принимается прогоном
  `backlog check-template`.
- `openspec/specs/batch-project-classification/spec.md` — обновится при синхронизации
  изменений.
- Окружение: карточный прогон не требует `WEBSEARCH_BASE_URL`, `WEBSEARCH_API_KEY`,
  `WEBSEARCH_ENDPOINT`; зависимости кода не меняются.
