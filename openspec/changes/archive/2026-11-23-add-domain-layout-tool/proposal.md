# Proposal

## Why

Размещение проектов по классификации сегодня не механизировано: принятые прогоны classify несут доменные метки L1/L2, но физическое дерево каталогов приходится создавать вручную, выдумывая слаги. У каждой записи выгрузки таксономии есть латинский слаг `code`, поэтому место проекта на диске вычислимо из принятой классификации. Владелец решил: механизм доменной раскладки живёт в этом репозитории; старый корневой проект `~/Workspace` со своей системой раскладки (`projects.yaml`, `layout/`-миграции) — вне изменения и не трогается.

## What Changes

- Новый инструмент `tools/layout/`: вход — каталог принятого прогона classify (`card.json` + `classification.json`) и корень репозитория; вычисляет путь `projects/<слаг L1>/<слаг L2>/<имя проекта>` по primary-меткам и слагам `code` из выгрузки таксономии `tools/classifier/taxonomy/`; создаёт каталоги; ведёт реестр происхождения в корне дерева; идемпотентен.
- Новый навык-обёртка `domain-layout` в `.claude/skills/` (плюс симлинк в `.zcode/skills/`): вызывает инструмент на беклоге classify и показывает итог.
- Реестр происхождения — файл `projects/layout-registry.json` в корне дерева, фиксирует, что и из какой карточки сформировано; дерево и реестр не коммитятся, gitignore репозитория пополняется строкой `/projects/`.
- Выгрузка таксономии не меняется: слаги уровней — существующее поле `code` записей.
- Коллизия имени проекта в пределах L1/L2 разрешается префиксом организации из карточки; L3 и L4 в путь не входят; организация и группа в путь не входят.

## Capabilities

### New Capabilities

- `domain-layout`: физическая раскладка проектов по доменной классификации — вычисление пути из принятого прогона classify, создание каталогов, реестр происхождения в корне дерева, некоммитимость дерева.

## Impact

- Этот репозиторий: новый uv-подпроект `tools/layout/`, навык `.claude/skills/domain-layout/SKILL.md` (+ симлинк `.zcode/skills/domain-layout`), новая спека `openspec/specs/domain-layout/`, строка `/projects/` в `.gitignore`.
- Не меняется: классификатор `tools/classifier/`, операция classify и её шаблон, пакетные прогоны классификации, старый корневой проект `~/Workspace` и его файлы.
