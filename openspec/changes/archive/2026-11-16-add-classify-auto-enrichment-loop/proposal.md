# Proposal

## Why

Прогоны пакетной авто-классификации (WRSP-026) массово падают по `needs_confirmation`: утилита возвращает отрывы primary от вторых кандидатов меньше margin, и элемент получает `failed`, хотя данные классификации близки к уверенным. Повторная генерация не лечит: эмбеддинги дают тот же результат на том же входе. Помочь может только изменение входа — дополнение карточки данными из уже выбранного источника. Ручная операция `classify` имеет такой цикл; авто-операции его нет.

## What Changes

- В шаблон `templates/classify-project-auto.md` добавляется цикл дополнения: при коде возврата `1` (`needs_confirmation`) исполнитель-автомат анализирует `reasons` утилиты, дополняет карточку по данным выбранного источника и повторяет вызов утилиты — до трёх попыток в одном беклоге.
- Карточка перезаписывается по каноническому пути `projects/{штамп}.cards/item-NN.json`; счётчик и ход дополнений фиксируются во фронтматтере (`enrichment_attempts`).
- Код возврата `2` (ошибка входа или окружения) дополнением не обрабатывается — отказ элемента сразу.
- После исчерпания трёх попыток — текущее поведение: `failed` с причиной `needs_confirmation` и сохранёнными данными последней классификации.
- Новый беклог при попытках не порождается: цикл живёт внутри одного беклога элемента.

## Capabilities

### New Capabilities

— (нет)

### Modified Capabilities

- `batch-project-classification`: добавляется требование «Цикл дополнения в авто-режиме» — поведение элемента по коду возврата `1` меняется с немедленного отказа на до трёх попыток дополнения и повторного прогона.

## Impact

- `templates/classify-project-auto.md` — группа 4 разрастается на цикл дополнения (~40 строк), версия шаблона 1.0.0 → 1.1.0.
- Спека `batch-project-classification` — одно ADDED-требование с двумя сценариями (зеркалит «Цикл дополнения данных» ручной операции `classify`).
- Навык `classify-batch`, оркестратор, контракт записи — не меняются: попытки невидимы за границей беклога элемента.
- Runtime — до 3 вызовов утилиты и 2–3 лишних шага агента на элемент; стоимость эмбеддингов мала.
- Задача [WRSP-026](https://github.com/united-software-platform/workspace/issues/16) — решение фиксируется комментарием.
