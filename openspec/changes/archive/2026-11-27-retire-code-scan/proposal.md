# Retire: code-scan (docker-механизм tldr-сканирования)

## Why

Механизм сканирования кода образом `ghcr.io/united-software-platform/tldr-code` через docker снесён
физически: задачи `tldr-scan`/`tldr-scan-ext` из `mise.toml` выпали, скрипты `tools/tldr/scan.sh` и
`tools/tldr/gateway.py` удалены из рабочего дерева, остаток `tools/tldr/__pycache__` снят, локальных
docker-образов нет. Спека `code-scan` — последний документированный след механизма. Рабочее
сканирование теперь — нативный CLI `tldr` (tldr-cli 0.4.0), закреплённый глобально через mise;
потребность в capability `code-scan` отпала.

Единственный потребитель механизма вне `code-scan` — спека `dev-work-format`: её контракт связывает
коммиты со «слепком tldr» (файлы `01-tree.json`, `03-structure.json`), который больше никто не
производит. Связка снимается той же правкой, чтобы в спеках не осталось следов снесённого механизма.

## What Changes

- **REMOVED** — capability `code-scan` целиком, все 12 требований: скрипт `tools/tldr/scan.sh`,
  шлюз `tools/tldr/gateway.py`, файл запроса `.tldr/scan-request.json`, переменные `TLDR_*`,
  коды возврата контейнера.
- **MODIFIED** — `dev-work-format`, требование «Структура YAML-контракта работы»: шапка выгрузки
  без полей слепка (имя слепка, дата съёмки, оговорка о неизвестной ревизии).
- **REMOVED** — `dev-work-format`: «Пара коммит—слепок по нормализованному пути» и
  «Аннотации слепка в паре» — слепок tldr был единственным источником пар.
- Purpose `dev-work-format` переписывается без слепка tldr (дельты на Purpose нет — правится при
  apply, формулировка в tasks.md).

Вне изменения:

- `.tessera/rules/environment.md` — ENV-006 (`tldr-scan`, `tldr-scan-ext`) и упоминание
  «одноразовые прогоны (tldr-сканирование)» в ограничениях. Файл управляется поставкой tessera:
  правится апстрим, в репозитории tessera-plugin, а не здесь.
- Записи `backlog/workflow/…` с упоминаниями tldr — исторические свидетельства прогонов, не трогаются.

## Impact

- Спеки: `openspec/specs/code-scan/spec.md` — удаляется целиком (git rm при apply);
  `openspec/specs/dev-work-format/spec.md` — 1 требование изменено, 2 удалены, Purpose переписан.
- Кода в репозитории нет: скрипты механизма сняты физически до этого изменения.
- Ссылку `docs/work-format.md` дельта сохраняет как есть: документ отсутствует в репозитории и
  сейчас — несоответствие предсуществующее, в это изменение не входит.
