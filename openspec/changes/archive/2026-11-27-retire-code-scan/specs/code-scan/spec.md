# code-scan Specification (delta)

## REMOVED Requirements

### Requirement: Запуск сканирования скриптом инструмента

**Reason:** механизм снесён — `tools/tldr/scan.sh` удалён, docker-образ сканирования не используется.

### Requirement: Проект недоступен сканированию для записи

**Reason:** требование описывало механику docker-прогона, механизм снят.

### Requirement: Отчёт на каждую команду

**Reason:** набор команд и отчётов принадлежал снесённому контейнерному сканированию.

### Requirement: Команды по истории git только при наличии репозитория

**Reason:** команды `hotspots`/`churn` выполнял снесённый docker-прогон.

### Requirement: Сканирование стороннего проекта по файлу запроса

**Reason:** шлюз `tools/tldr/gateway.py` и задача `tldr-scan-ext` удалены.

### Requirement: Валидация запроса шлюзом

**Reason:** шлюза больше нет — валидировать нечего.

### Requirement: Разрешённые корни сканирования

**Reason:** переменная `TLDR_SCAN_ROOTS` принадлежала снятому шлюзу.

### Requirement: Файл результата с идентификатором запроса

**Reason:** файл `.tldr/scan-result.json` производил снятый шлюз.

### Requirement: Отчёты сторонних сканирований вне git

**Reason:** каталоги отчётов `reports/<report_name>` больше не создаются.

### Requirement: Задача mise для сканирования проекта

**Reason:** задача `tldr-scan` из `mise.toml` выпала, сканирование выполняется нативным CLI `tldr`.

### Requirement: Коды возврата сканирования контейнером

**Reason:** контейнерного сканирования нет — коды возврата контейнера не нормируются.

### Requirement: Настройка сканирования через mise

**Reason:** переменные `TLDR_IMAGE`/`TLDR_EXT`/`TLDR_EXCLUDE` и образ по умолчанию принадлежали
снесённому механизму.
