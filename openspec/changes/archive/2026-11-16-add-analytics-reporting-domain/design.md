# Design

## Context

Классификация аналитических систем упирается в пробел L1: домена аналитики нет, A&B-метки строятся из «Управления информацией», «Управления бизнесом» и «Госсектора» — доменов, ни один из которых не называет аналитику по существу. Требование — proposal.md; смежные изменения уже в архиве (`merge-taxonomy-and-ab-labels` дал метки A&B, `add-batch-project-classification` — пакеты). Таксономия сейчас: L1 — 16 записей, счётчики манифеста 16/35/24/34.

## Goals / Non-Goals

Goals:

- аналитические карточки получают родной primary L1 или осмысленную A&B-метку с «Аналитикой и отчётностью»;
- запись не порождает новую пару-близнеца (замер близости ≤ 0.83 к соседям).

Non-Goals:

- изменения утилиты, шаблонов и авто-операции — поведение не меняется, меняется только справочник;
- заострение описаний других записей L1.

## Decisions

### D1. Формулировка — через потребление данных, не инфраструктуру

Описание строится вокруг выводов и отчётности: «сбор данных, подготовка сводных отчётов, дашборды, BI-аналитика, визуализация, аналитические материалы для принятия решений». Это разводит запись с DOM-010 «Инженерия данных» (конвейеры-инфраструктура) и DOM-015 «Управление информацией» (документооборот). Проверка — замер косинусной близости к трём соседям до слияния в справочник: ≤ 0.83 на каждого, иначе формулировка правится до записи.

### D2. Идентификатор и код — по образцу уровня

DOM-017 — следующий свободный номер; код `analytics-reporting` — kebab-case по образцу `business-management`, `information-management`. Поля двуязычные, стиль — как у существующих записей.

## Risks / Trade-offs

- [Аналитический смысл тянет и «Инженерию данных»] → осознанно: BI-системы включают конвейеры; A&B-метка «Аналитика и отчётность & Инженерия данных» для таких карточек честна.
- [Существующие карточки меняют primary L1] → ожидаемый эффект улучшения: прогон пакета 20261116171306 показал бы DOM-017 в кандидатах; перепрогон — задача проверки.

## Migration Plan

Чисто добавляющая правка справочника, манифеста и одного счётчика теста. Откат — удаление записи и возврат счётчиков; следов в данных нет.
