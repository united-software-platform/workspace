# Spec Delta

## ADDED Requirements

### Requirement: Автопринятие A и B-метки
Итог утилиты с объединённой меткой уровня «A & B» — кандидаты в пределах margin, соединённые общей меткой, код возврата `0` — SHALL считаться чистым результатом: элемент получает статус `classified`, метка фиксируется как принятая классификация.

#### Scenario: Метка A и B принята авто-режимом
- **WHEN** утилита вернула код `0` с объединённой меткой уровня «A & B» по кандидатам в пределах margin
- **THEN** элемент получает статус `classified`, метка фиксируется как принятая классификация

#### Scenario: Отказ остаётся только для порога
- **WHEN** утилита вернула `needs_confirmation` по непройденному порогу confidence
- **THEN** элемент получает статус `failed` с причиной `needs_confirmation`, данные классификации сохраняются в записи прогона
