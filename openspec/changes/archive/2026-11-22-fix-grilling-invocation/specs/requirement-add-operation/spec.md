# Spec Delta

## MODIFIED Requirements

### Requirement: Прожарка BR по шаблону карточки

Беклог requirement-add SHALL содержать задачу вызова навыка `/mattpocock-skills:grilling`
с передачей намерения — значения `requirement` фронтматтера и краткой формулировки: навык
ведёт прожарку раундами вопросов фронтира с рекомендованными ответами, факты выясняет сам,
решения остаются за владельцем, конец — пустой фронтир и подтверждённое общее понимание.
Ответы раундов исполнитель разносит по девяти полям карточки: ID (вида `BR-NNN`), Name,
Description, Rationale, Business Outcome, Success Criteria, Priority (`Must` / `Should` /
`Could` / `Won't`), Status, Source. Прожарка MUST продолжаться, пока фронтир не пуст и каждое
поле не заполнено; выдумывать содержимое полей запрещено — недостающее выясняется у владельца.
Заполненная карточка записывается во фронтматтер значением `br_card`.

#### Scenario: Намерение передано навыку

- **WHEN** задача прожарки исполняется
- **THEN** навык `/mattpocock-skills:grilling` вызван со значением `requirement` и краткой формулировкой, раунды вопросов идут до пустого фронтира

#### Scenario: Прожарка заполняет все поля

- **WHEN** прожарка завершена
- **THEN** `br_card` несёт все девять полей, и каждое заполнено словами владельца, а не выдумано исполнителем

#### Scenario: Поле без сведений

- **WHEN** у владельца нет сведений для поля (например, Source)
- **THEN** исполнитель спрашивает владельца и вносит ответ; вопрос не снимается пометкой «нет» без ответа владельца
