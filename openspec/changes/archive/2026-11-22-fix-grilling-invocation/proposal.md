# Proposal

## Why

Задача 2.2 шаблона называет навык `/mattpocock-skills:grilling`, но не вызывает его: механика
прожарки описана как ручная — «уточнять формулировки, пока каждое поле не заполнено», —
и намерение навыку не передаётся. Контракт навыка иной: он сам ведёт допрос раундами —
пронумерованные вопросы фронтира с рекомендованными ответом, факты выясняет сам, решения
остаются за владельцем, конец — пустой фронтир и подтверждённое общее понимание. Без вызова
с намерением прожарка деградирует до самостоятельного анкетирования исполнителем — навык
не работает «через упоминание». Владелец нашёл недоработку сам и велел внести её раньше
завершения линтинг-изменения.

## What Changes

- Задача 2.2 шаблона переписана на вызов навыка: `/mattpocock-skills:grilling` вызывается
  с переданным намерением — значение `requirement` фронтматтера и краткая формулировка
  задачи 2.1; навык ведёт раунды до пустого фронтира, ответы раундов исполнитель разносит
  по девяти полям карточки. Шаблон 1.3.0 → 1.4.0.
- Требование «Прожарка BR по шаблону карточки» уточнено: задача прожарки — вызов навыка
  с намерением; добавлен сценарий «Намерение передано навыку».
- Вне рамок: состав девяти полей, правило номера BR-NNN, запрет выдумывать — без изменений;
  линтинг (задачи 2.4–2.5) и стоп-знак не правятся.

## Capabilities

### New Capabilities

_Нет_: меняется механика существующей задачи операции.

### Modified Capabilities

- `requirement-add-operation`: требование «Прожарка BR по шаблону карточки» — прожарка
  исполняется вызовом навыка grilling с передачей намерения вместо ручного уточнения
  формулировок исполнителем.

## Impact

- Правится `templates/requirement-add.md` — задача 2.2 и версия шаблона 1.4.0. Навыки-
  обёртки, `tools/reqlint/`, артефакты `docs/requirements/` не правятся.
- Зависимость: плагин `mattpocock-skills` 1.3.2 — навык `/mattpocock-skills:grilling` уже
  зафиксирован в спеке операции, новая зависимость не появляется.
- Порядок: применяется после архивации `rename-formular-skill-to-requirement-add`
  (capability уже носит имя `requirement-add-operation`).
