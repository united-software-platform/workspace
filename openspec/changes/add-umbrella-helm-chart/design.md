# Design

## Context

Кластер k3s после change `unify-environment` пуст; ENV-007 объявил поставку сервисов
helm-манифестами зонта. Дизайн прошёл прожарку с владельцем: первый потребитель набора — сам
workspace, состав — PostgreSQL, OpenSearch, S3 (MinIO); все решения раундов подтверждены.

## Goals / Non-Goals

**Goals:**

- общий набор из трёх сервисов одним чартом и одной командой применения;
- чистые сервисы без init-наполнения: потребители разделяют их внутри (ENV-007);
- секреты только в `.env`, версии образов закреплены.

**Non-Goals:**

- HA-развёртывания, реплики, ресурсы/лимиты — локальная разработка, по одному экземпляру;

- init-Job'ы (создание БД, индексов, бакетов) — наполнение остаётся за потребителями;

- Ingress, registry, мониторинг — с реальной потребностью.

## Decisions

- **Каркас с шаблоном на сервис вместо values-фабрики** (раунд 1 прожарки): фабрика из четырёх
  полей стала бы ограничителем — реальным сервисам нужны пробы и хранилище; первый настоящий
  сервис даёт первый настоящий шаблон.
- **Состав набора** (раунд 2): PostgreSQL 17.12, OpenSearch 3.9.0 single-node (`discovery.type`,
  heap 512m), MinIO с тегом `RELEASE.2026-09-19T17-05-25Z`. Мажоры выбраны по преемственности
  (17-я линия postgres уже работала в окружении) и актуальности на 2026-11; теги полные, не
  `latest`.
- **Креды через `--set` из задачи mise**: секреты читаются из `.env` (паттерн embeddings
  расширяется), шаблон требует их через `required` — пустой секрет останавливает установку
  сообщением, а не молчанием.
- **PVC local-path по 10Gi на сервис**: класс хранения k3s из коробки; размеры в values.
- **Доступ только port-forward** (ENV-003): ClusterIP, включая БД; исключений нет.
- **Метки**: селекторы через стандартную `app.kubernetes.io/component` (значения postgres /
  opensearch / minio) поверх общих меток чарта — самодельных меток нет.
- **Неймспейс применения флагом `-n`** из `WORKSPACE_NAMESPACE` (умолчание `workspace`),
  не в values: один чарт — разным потребителям без правки values.

## Risks / Trade-offs

- [OpenSearch требует `vm.max_map_count=262144` на хосте] → названо предусловием README;
  без него под не стартует, сообщение видно в `kubectl describe pod`.
- [Каждый сервис в одном экземпляре] → принято: локальная разработка; рост потребностей
  влечёт реплики отдельной правкой шаблона.
- [helm в среде ветки отсутствует] → `helm lint` и применение — проверки хоста; шаблоны написаны
  штатной механикой helm, YAML-значения просмотрены.

## Migration Plan

1. Переписать чарт и артефакты change под прожаренный дизайн, прогнать `openspec validate`.
2. На хосте владельца: `helm lint deploy/workspace`, `mise run k3s-apply` с заполненным `.env`,
   port-forward-проверки трёх сервисов.
3. Archive изменения после приёмки.
