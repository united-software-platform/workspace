## Условия прогона

- Дата: 2026-11-14; скрипт `scripts/live_run.py` (одноразовый, в поставку не входит).
- Эндпоинт: живой прокси, модель по `EMBEDDINGS_MODEL` — 768 измерений.
- Корпус: 3 вымышленных примера из `tools/classifier/taxonomy/example_project.json`.
- Порог: 0.5 (стартовый, не калиброванный).

## Наблюдения

1. **Прокси требует суффикс `/v1`.** Первый прогон с `{base}/embeddings` вернул 404;
   клиент дописывает `/v1`, если суффикса нет — правка вошла в `HttpEmbeddingClient`.
   Риск design D1 подтверждён и закрыт.
2. **Primary L1 совпал с ожидаемой разметкой на всех трёх примерах** (DOM-003
   «Торговля и коммерция»), confidence 0.70–0.76, порог 0.5 пройден.
3. **Шкала косинуса у модели сжата**: вторичные кандидаты отстоят от primary всего
   на 0.03–0.06. Порог 0.5 проходится всюду — для раннего отсева слабых карточек
   он бесполезен; калибровка порога — этап 5, значение стартовое.
4. **L2–L4 первичны не всегда точно**: у «Moss & Maple» primary L2 SUB-033 (каталог),
   а не SUB-035 (рекомендации); у «Northstar Market» primary L4 SOL-031, хотя пример
   ожидает иного. Точность уровней — открытый вопрос этапа 5: корпус из трёх примеров
   статистики не даёт.
5. **Батч-запрос таксономии (109 текстов) прошёл одним вызовом**, нарезка на части
   не потребовалась — лимит прокси не достигнут.
