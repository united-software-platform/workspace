# Навык domain-layout

Обёртка доменной раскладки проекта: принимает беклог принятого прогона classify,
проверяет принятие классификации и вызывает утилиту `tools/layout/` — та вычисляет
путь `projects/<слаг L1>/<слаг L2>/<проект>`, создаёт каталоги и ведёт реестр
происхождения в корне дерева. Сам навык не вычисляет путь и не трогает файловую
систему — всё это делает утилита. Доменные понятия определены в
[глоссарии](../../../GLOSSARY.md).

## Вход

Вход навыка — путь к каталогу беклога прогона classify: что раскладываем, текстом вызова.

- Путь назван — навык не спрашивает его повторно.
- Вызов пуст — навык задаёт ровно один вопрос «какой прогон» и после ответа продолжает
  без повторных вопросов о недостающем вводе.

Прогон обязан нести контракты `card.json` и `classification.json` и принятую
классификацию. Корень дерева — корень этого репозитория, если владелец не назвал иной.
Дерево раскладки и реестр происхождения не коммитятся.

---

## Порядок

1. **Принять путь прогона** — по правилам раздела «Вход».
2. **Проверить прогон до вызова утилиты** — каталог существует, `card.json`
   и `classification.json` на месте, беклог несёт `confirmed.accepted: true`.
   Непринятый прогон — стоп с названным препятствием: раскладка фиксирует только
   присвоенную классификацию.
3. **Вызвать утилиту** с каталогом прогона и корнем пространства:

   ```bash
   cd tools/layout && uv run layout <каталог прогона> --root <корень>
   ```

4. **Показать итог** — целевой путь, созданные каталоги и запись реестра
   происхождения: что и из какой карточки сформировано.

---

## Итог

Итог показывается владельцу целиком: целевой путь проекта, статус каталога — создан
либо существовал как выполненный ранее, — запись реестра происхождения. Прогон не
сопровождается коммитом: дерево раскладки не коммитится.

---

## Отказы

Отказы утилиты передаются владельцу как есть, по кодам возврата:

- `1` — состояние не позволяет выполнить прогон: прогон не принят, путь невычислим,
  коллизия имён, целевой путь занят файлом;
- `2` — ошибка окружения: файлы прогона или выгрузки таксономии не найдены либо
  не разбираются.
