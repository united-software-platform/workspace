Документ для тех, кто правит shop-cli: устройство репозитория, сборка выпуска, блок бейджей, проверки
и нормы. Применение shop-cli описано в [`README.md`](./readme.md), задачи за пределами основного
пути — в [документе кейсов](./use-cases.md).

> **Образец:** `CONTRIBUTING.md` адресован правящему систему — `DGN-001`; голос безличный — `DGN-009`.
> Документ заводится, когда систему правят не те, кто её применяет, — `DGN-002`.

## Сборка выпуска

Номер версии повышается правкой `VERSION` отдельным коммитом. Выпуск собирается из ветки `main`
командой `make release`: она читает номер из `VERSION` и кладёт архивы для Linux и macOS
в каталог `dist/`. Архивы выкладываются на страницу выпусков вручную.

## Блок бейджей

Блок бейджей стоит в [`README.md`](./readme.md) между заголовком и назначением. Бейдж версии
динамический: номер вычисляется сервисом бейджей из носителя в репозитории, ручной копии номера
в `README.md` нет.

| Бейдж | Источник значения | Режим | Цель ссылки |
|-------|-------------------|-------|-------------|
| `version` | файл `VERSION` в ветке `main` | `dynamic/regex`, префикс `v` добавляется отображением | страница выпусков `example/shop-cli` |
| `license` | статическое значение, носителя нет | — | страница лицензии MIT в реестре SPDX |

Ограничения блока:

- **репозиторий должен быть доступен анонимно** — сервис бейджей читает `VERSION` без
  аутентификации;
- **переименование `VERSION` ломает бейдж молча** — после правки носителя бейдж открывают глазами.

> **Образец:** карта бейджей ведётся здесь, если проект держит `CONTRIBUTING.md`, — `DGN-004`.
> Состав таблицы совпадает с блоком бейджей образца `README.md`.

## Проверки

Проверки прогоняются до отправки изменений, каждая — своей командой:

```bash
make test                    # модульные тесты
make lint                    # стиль исходников
sh tools/make-lint/check.sh  # объём секций Makefile
```

Полный перечень целей печатает `make help`.

> **Образец:** каждая проверка названа одной командой — `DGN-008`; перечень целей не повторяется —
> `DGN-011`.
