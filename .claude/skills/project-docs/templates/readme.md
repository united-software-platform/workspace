Выгружает каталог товаров вашего магазина в файл CSV или JSON — для маркетплейса или учётной системы.
Здесь — путь от установки до первой проверенной выгрузки. Другие задачи — в [документе кейсов](./use-cases.md),
правка самого shop-cli — в [`CONTRIBUTING.md`](./contributing.md).

> **Образец:** блок бейджей между заголовком и назначением — `DGN-004`, ссылки бейджей — `DOC-015`.
> Назначение называет читателя и документы других ролей — `DGN-001`. Голос документа — «вы», `DGN-009`.

## Что нужно

- Linux или macOS с оболочкой `sh`.
- Адрес API вашего магазина и токен с правом чтения каталога — токен выдаёт панель администратора
  магазина.

> **Образец:** разделы идут по каркасу `DGN-003`: «Что нужно», шаги, «Куда дальше», затем только
> «Ограничения» и «Лицензия».

## Шаг 1. Установить shop-cli

Скачайте архив последнего выпуска для вашей системы со
[страницы выпусков](https://github.com/example/shop-cli/releases), распакуйте его и положите
`shop-cli` в каталог из `PATH`:

```bash
tar -xzf shop-cli-linux-amd64.tar.gz
sudo mv shop-cli /usr/local/bin/
shop-cli --version
```

Последняя команда печатает номер версии — shop-cli установлен.

---

## Шаг 2. Подключить магазин

Передайте shop-cli адрес API и токен:

```bash
shop-cli login --url https://shop.example.com/api --token <токен>
```

shop-cli проверяет токен и запоминает подключение. Сообщение `Подключено: shop.example.com`
означает, что можно выгружать.

Подробнее — [кейс 1](./use-cases.md#кейс-1-хочу-выгружать-каталог-второго-магазина).

> **Образец:** шаг, у которого есть кейс, заканчивается строкой «Подробнее — кейс N» — `DGN-005`.
> У шага 1 кейса нет, поэтому строки нет.

---

## Шаг 3. Выгрузить каталог

```bash
shop-cli export --format csv --out catalog.csv
```

В текущем каталоге появляется `catalog.csv`: по строке на товар, с артикулом, названием, ценой
и остатком.

Подробнее — [кейс 2](./use-cases.md#кейс-2-хочу-выгрузить-только-часть-каталога).

---

## Шаг 4. Проверить выгрузку

```bash
shop-cli check catalog.csv
```

Если проверка не нашла ошибок, она печатает `Готово к отправке`, и файл можно передавать
маркетплейсу.

Подробнее — [кейс 3](./use-cases.md#кейс-3-хочу-понять-почему-выгрузка-не-прошла-проверку).

## Ограничения

- **Только чтение.** shop-cli не меняет товары в магазине: исправлять цены и остатки нужно в панели
  администратора, после чего выгрузить каталог заново.
- **Один файл — один формат.** Чтобы получить CSV и JSON, запустите выгрузку дважды.

> **Образец:** здесь же называется обязательный бейдж, которому неоткуда взять значение, и причина —
> `DGN-004`. У этого образца оба обязательных бейджа есть.
