## Кейс 1. Хочу выгружать каталог второго магазина

**Когда.** У меня два магазина, а основной путь подключил только первый.

**Что делаю.** Подключаю второй магазин под своим именем профиля и называю профиль при выгрузке:

```bash
shop-cli login --profile spb --url https://spb.shop.example.com/api --token <токен>
shop-cli export --profile spb --format csv --out spb.csv
```

**Что получаю.** Файл `spb.csv` с каталогом второго магазина. Выгрузка без `--profile`
по-прежнему идёт из первого.

> **Образец:** заголовок `## Кейс N. <цель от первого лица>` и метки «Когда», «Что делаю»,
> «Что получаю» в этом порядке — `DGN-006`. Нумерация сквозная — `DGN-007`.

## Кейс 2. Хочу выгрузить только часть каталога

**Когда.** Маркетплейсу нужна одна категория или только товары, изменённые с прошлой выгрузки.

**Что делаю.** Передаю категорию или дату ключом:

```bash
shop-cli export --category shoes --out shoes.csv
shop-cli export --updated-since 2026-10-01 --out changes.csv
```

**Что получаю.** Файл только с выбранными товарами. Ключи сочетаются: `--category shoes
--updated-since 2026-10-01` даёт обувь, изменённую с первого октября.

## Кейс 3. Хочу понять, почему выгрузка не прошла проверку

**Когда.** `shop-cli check` не напечатал `Готово к отправке`, и я не знаю, можно ли отправлять файл.

**Что делаю.** Смотрю код возврата проверки:

```bash
shop-cli check catalog.csv; echo $?
```

И действую по коду:

| Код | Что значит | Что делаю |
|-----|------------|-----------|
| `0` | Выгрузка прошла проверку | Отправляю файл маркетплейсу |
| `1` | В выгрузке есть товары без цены или артикула | Заполняю их в панели администратора и выгружаю каталог заново |
| `2` | Файл не найден или не читается | Проверяю путь к файлу и права на чтение |

**Что получаю.** Файл, который проверка принимает с кодом `0`.

**Если не вышло.** Запускаю проверку с ключом `--verbose`: она печатает номера строк с ошибками,
и по артикулу я нахожу товар в панели администратора.

> **Образец:** коды возврата сведены в таблицу «Код / Что значит / Что делаю» — `DGN-012`.
> Дополнительная метка стоит только после «Что получаю» — `DGN-006`.
