
контекст: система управления рабочим пространством разработчика
возможности гибко управлять, собирать и агрегировать данные о проектах(гит, ast и другие метрики), кейсах
производить анализ проектов, производить гибридный поиск по данным в проектах

цель: заложить базовые функции работы с пространством

группы действий:

проект
  завести проект: заполнить инфо о проекте
  удалить проект: вывести из рабочего пространства
  поднять проект: создать проект, установить базовые компоненты, опубликовать на gh 
  редактировать проект редактировать данные проекта 

анализ
  анализировать проект

раскладка
  изменить раскладку проектов
