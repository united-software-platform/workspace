# Классификация проекта {{subject}}

Беклог операции classify-project: найти проект по названию в интернете, владелец выбирает
ближайший источник, по нему составляется карточка проекта, навык /classify принимает
классификацию — принятием беклог закрывается.

Значения операции несёт фронтматтер — второй раз они не собираются
(BKL-005; текст нормы — `backlog norms --rule BKL-005`). Задачи исполняются
по порядку. Порядок исполнения — отметки задач, выводимый признак «выполнено ранее»,
стоп-знак — задан BKL-006 (`backlog norms --rule BKL-006`) и BKL-007 (`backlog norms --rule BKL-007`),
а его носитель — `{{runner}}`: прочитать его перед первой задачей; здесь он
не пересказывается (BKL-008; текст нормы — `backlog norms --rule BKL-008`).
